# Floatspace Bible

## Mission
Floatspace is not a notes app. It is a calm thinking space beside macOS.

## Core Rules
- One workspace = one screen.
- No infinite canvas.
- Cards are the only object in MVP.
- AI assists thinking; it never replaces it.
- Workspace is always persistent.
- Simplicity beats feature count.

## MVP
- Drag to create cards
- Text only
- Move
- Resize
- Delete
- Autosave
- Persistent workspaces

## AI
Workspace analysis uses a temporary overlay.
AI never edits cards automatically.

## Never Build
- Infinite canvas
- File manager
- Browser
- PDF editor
- Miro clone
- Obsidian clone
